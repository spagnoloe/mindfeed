## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `spagnoloe/mindfeed` via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Design

UI values come from the Claude Design prototype. Before reading it, see `docs/design.md` for a cheap way to read it and where each screen and behaviour lives.
